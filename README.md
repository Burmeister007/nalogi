# Самозанятость в РФ — справочник НПД

Справочник по налогу на профессиональный доход: регистрация, налоги и вычет, лимит 2,4 млн ₽ по датам, чеки, соцгарантии, господдержка, банки и кредиты, подводные камни, штрафы, судебная практика и законодательная база. Редакция от 28.10.2026.

Содержимое зашифровано (AES-256-GCM, ключ через PBKDF2-SHA256) и расшифровывается в браузере.
Открывается по ссылке с ключом доступа.
